# Agenda

It's an site for scheduling appointments at a beauty salon, but it can be adapted for any other type of business.

## Installation

Simply run the command in the command prompt to install the dependencies and execute the initialization command.

```bash
npm install
```

## Run
```bash
npm start
```

# Learnings

In this project, I am expected to improve my code versioning using Git, as well as gain experience with React.js, learn how to do unit testing with Jest, and learn more about the Clean Code philosophy.
